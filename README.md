# Responsive Blog Website Using Media Queries and Bootstrap

## Experiment Aim
To build a blog website using media queries and Bootstrap to ensure that it adapts well to different screen sizes.

## Description
This project is a responsive blog website developed using HTML, CSS, Bootstrap, and CSS media queries. It displays blog articles related to technology, travel, lifestyle, and web development.

The website uses Bootstrap's grid system and responsive components to adjust the layout according to the screen size. CSS media queries are used to improve the appearance of the website on mobile phones, tablets, and desktops.

## Technologies and Resources Used
- HTML5
- CSS3
- Bootstrap 5
- CSS Media Queries
- Visual Studio Code
- Web Browser
- GitHub and GitHub Pages (if used for hosting)

## Features
- Responsive navigation bar with a collapsible menu.
- Welcome section with a heading and description.
- Blog cards containing images, titles, and descriptions.
- Sidebar displaying blog information and categories.
- Responsive layout for different screen sizes.
- Hover effects on blog cards.
- Footer section with copyright information.
- Bootstrap grid system for arranging content.

## How the Website Works
1. The navigation bar provides links to different sections of the website.
2. The welcome section introduces the blog.
3. Blog cards display articles about different topics.
4. The sidebar provides information about the blog and its categories.
5. Bootstrap classes arrange the content into responsive rows and columns.
6. CSS media queries adjust spacing, font sizes, and image heights for smaller screens.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the `index.html` file in a web browser.
3. Ensure that an internet connection is available to load Bootstrap and the external images.
4. Resize the browser window or open the website on different devices to test its responsiveness.

## Result
A responsive blog website was successfully developed using HTML, CSS, Bootstrap, and media queries. The website adjusts its layout to provide a better viewing experience on desktops, tablets, and mobile devices.
